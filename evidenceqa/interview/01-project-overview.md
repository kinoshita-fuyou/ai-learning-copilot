# EvidenceQA 项目概述与简历要点

## 一句话定位

EvidenceQA 是一个可追溯的企业知识库问答系统：上传文档后自动切分、向量化，
用户提问时先检索最相关的原文片段，再生成回答并附上可点击核对的引用来源。

## 解决什么问题

企业内部制度、产品手册、研发规范散落在各处，员工问 AI 得到"看起来很对"的答案，
却无法确认来源。EvidenceQA 的核心差异是 **回答必须回到原文**：引用可溯源、
质量可评测、离线可演示。

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 语言 | Python 3.14 | 类型注解贯穿全项目 |
| Web 框架 | FastAPI | 自动 OpenAPI 文档、Pydantic 校验、依赖清晰 |
| 存储 | SQLite | 文档正文 / 切块 / embedding 分表存储，零部署成本 |
| 检索 | 特征哈希 Embedding + BM25 混合检索 | 免 API Key、确定性、关键词与语义互补 |
| 回答 | Template / LLM 双 Provider | 接口一致，环境变量切换 |
| 测试 | pytest + TestClient | 38 个用例覆盖接口、切分、检索、问答、评测、鉴权、UI |
| 部署 | Docker Compose + GitHub Actions | 命名卷持久化、健康检查、push 自动回归 |

## 核心能力

- 文档接入：`.md` / `.txt` 上传，扩展名、编码、空内容、1 MB 大小四重校验
- 切分管线：段落优先 + 固定窗口 + 重叠上下文，保留字符范围用于溯源
- 混合检索：CJK 双字元特征哈希向量 + BM25 关键词，min-max 归一化后 alpha 融合
- RAG 问答：检索 → 拼 prompt → 生成回答 → 返回引用来源列表
- 检索评测：Recall@K、MRR、平均延迟，内置 21 道跨文档评测题（支持混合/纯向量模式对比）
- 可选鉴权：设置 `EVIDENCEQA_API_KEY` 后所有数据接口要求 `X-API-Key`，默认关闭
- Web 控制台：文档库 / 问答 / 检索 / 评测四个页签，纯原生前端
- 一键演示：`scripts/demo.sh` 重建演示库并启动服务

## 架构

```mermaid
flowchart LR
    U[用户] -->|上传/提问| C[Web 控制台]
    C --> API[FastAPI]
    API --> D[(SQLite 文档表)]
    API --> CH[切分管线]
    CH --> DB[(SQLite chunks + embedding)]
    API --> R[检索: 余弦相似度 Top-K]
    R --> A[回答生成: Template / LLM]
    A -->|回答 + 引用来源| C
    E[评测集 20 题] -->|Recall@K / MRR / 延迟| API
```

## 关键设计决策（面试故事线）

1. **先有评测，再有调优**：Day 5 就建立了 Recall@K / MRR 评测集，后续任何检索改动
   都有量化依据，而不是"感觉变好了"。
2. **Embedding 可替换**：本地特征哈希保证离线可跑、结果确定，接口与云端 Embedding
   对齐，接 OpenAI 兼容 API 时只改一个实现。
3. **正文、切块、向量解耦存储**：chunk 保留 `char_start/char_end`，来源可精确到
   原文位置；旧库缺 embedding 列可自动迁移回填。
4. **回答与引用绑定**：检索结果按文档标题 + 片段编号注入 prompt，返回的 sources
   与生成回答一一对应，幻觉可被用户直接核查。
5. **失败兜底**：检索为空时回答明确"未找到相关文档"，而不是硬编。

## 量化指标（演示时报告）

- 内置评测集 21 题：混合检索 Recall@K = 1.0、MRR = 1.0；纯向量基线 MRR = 0.9683，
  混合检索把一道关键词型问题从第 3 名提升到第 1 名
  （说明口径：本地特征哈希 + BM25 + 3 份小语料，是基线而非生产指标）
- 38 个自动化测试全绿，GitHub Actions CI 自动回归

## 面试时可能被追问的扩展点

- 换成真实 Embedding（BGE / OpenAI）后流程哪里要改？
- 数据量到百万 chunk 时全表扫描不行了，怎么上向量索引（FAISS / sqlite-vec）？
- 引用可信度怎么度量？重排（rerank）放在哪一层？
- 多用户权限怎么加？谁可以搜到哪份文档？
- 回答质量怎么评测？（LLM-as-judge、人工抽查、问答对扩充）
